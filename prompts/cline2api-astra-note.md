# یادداشت Astra — cline2api

اگر endpoint مدل عیار امن روی cline2api-workers است:

- Base: `https://<your-worker>.workers.dev/v1`
- Header: `Authorization: Bearer <API_KEY>`
- Model پیش‌فرض رایگان: `cline-free/deepseek-v4.1-flash`
- سازگار با OpenAI `chat.completions` و Anthropic `messages` (طبق آپ‌استریم)
