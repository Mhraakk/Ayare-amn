# پرامپت GPT-6 Astra برای عیار امن — راهنمای استفاده

این پوشه پرامپتی است که باید به **GPT-6 Astra** بدهی تا اپ **عیار امن** را از نظر اجرا، فیچر، تست دستی و اتوماتیک، MCP و دیپلوی Vercel کاملاً آماده کند.

منبع معماری تأییدشده:

`https://chatgpt.com/share/6aa01d51-85c4-83ea-9f64-6e4f32824e21`

## چه کار می‌کند

پرامپت انگلیسیِ کامل در فایل `GPT6-ASTRA-MASTER-PROMPT.md` است (برای تولید کد سازمانی، انگلیسی دقیق‌تر عمل می‌کند). آن فایل به مدل دستور می‌دهد که **به همین ترتیب** پیش برود:

1. **همه فایل‌هایی که داده‌ای** را لیست کند، نصب بودن و اجرایی بودن هر کدام را با دستور واقعی ثابت کند.
2. اپ را از نظر **همه فیچرها عملیاتی** کند (نه mock، نه «به‌زودی»). اول باگ شناخته‌شده لاگین بعد از ثبت‌نام (`Invalid login credentials`) را ببندد.
3. هسته حسابداری طلا و جواهر را واقعی پیاده کند: چارت حساب، دفتر کل دوطرفه اتمیک، دفتر وزن طلا، موجودی قطعه‌ای، فاکتور خرید/فروش، Blotter و PnL به‌روش FIFO، زنجیره هش، RLS.
4. **مهم‌ترین بند تو:** عملیات دستی و اتوماتیک بدون باگ. اگر ارور دید باید همان مسیر را درست کند و دوباره تست کند. دابل‌کلیک ثبت سند نباید دو بار پول/طلا کم کند.
5. اتصال MCP (حداقل Vercel MCP برای دیپلوی؛ Foundry/Hermes طبق گزارش معماری).
6. **فقط بعد از سبز شدن گیت‌ها** کل اپ را روی Vercel دیپلوی کند و روی دامنه واقعی لاگین + یک سند حسابداری را اسموک کند.
7. اگر هر دفتر، تست طلایی، MCP یا دیپلوی ناقص ماند باید صریح بنویسد: `PRODUCTION READY: NO`.

## چطور به Astra بدهی

1. کل سورس اپ عیار امن را در همان چت بگذار (ریپو، zip، یا همه فایل‌ها).
2. کل محتوای `GPT6-ASTRA-MASTER-PROMPT.md` را از خط جداکننده به بعد کپی کن و **کوتاه نکن**.
3. اگر کلید Supabase / Vercel / MCP داری، در env پروژه یا تنظیمات MCP همان محیط بگذار — داخل پرامپت توکن نگذار.
4. بگذار مدل تا انتهای گزارش `AYARE AMAN READINESS REPORT` جلو برود.

## اگر فقط همین ریپو را داری

الان این ریپو تقریباً خالی است (`README.md` + پرامپت‌ها). Astra بدون سورس اپ نمی‌تواند دیپلوی واقعی بدهد. سورس کامل را به همان چت ضمیمه کن.

## خروجی که باید از Astra بگیری

گزارش انتهایی با این فیلدها:

- `PRODUCTION READY: YES` یا `NO`
- جدول فایل‌ها: نصب شده؟ اجرایی؟ اثبات با کامند
- ماتریس فیچر (لاگین، داشبورد، دفتر کل، طلا، فاکتور، RLS)
- اسکریپت عملیات دستی + باگ‌های پیدا و بسته‌شده
- وضعیت MCP و URL پروداکشن Vercel

اگر `PRODUCTION READY: YES` بود ولی URL ورسیل یا تست دستی خالی بود، گزارش را قبول نکن.
